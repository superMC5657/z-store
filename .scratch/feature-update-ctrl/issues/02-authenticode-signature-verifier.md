# Issue 02: Windows 平台安装包完整性核验（已调整为仅 SHA-256）

Status: resolved

## 描述

在下载完成、执行安装之前，增强 Windows 二进制安装文件的安全性核验：

1. 优先执行官方 SHA-256 哈希硬比对（现有机制，哈希不符直接销毁）；
2. 未提供官方哈希时，流式哈希仍会计算并持久化至本地数据库以备审计，状态明确标识为未校验，禁止虚假声明已通过官方校验；
3. 编写测试或 Mock 测试覆盖校验逻辑。

## Comments

- 针对未提供官方哈希的开源免安装 ZIP/二进制tarball 包，降级为本地计算并标记未校验。

## Answer

已移除发布者指纹强验逻辑，安装链路统一收敛为 SHA-256 流式校验：

1. 在安装链路中保留前置防篡改校验，哈希不符立即销毁临时文件并阻断安装流程；未提供官方哈希的开源绿色压缩包标记为未校验；
2. `catalog.json` 中已移除发布者指纹字段；详情弹窗中的 Trust Box 展示栏（`GitHub Release Verified` 与 SHA-256 状态行）已移除，校验收敛为默认行为不再单独展示，仅在安装包行保留官方 SHA-256 值标签，下载时仍强制流式校验。
