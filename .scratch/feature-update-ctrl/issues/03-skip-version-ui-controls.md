# Issue 03: 更新中心跳过菜单与设置中心规则管理视图

Status: resolved

## 描述

完善前端对细粒度更新控制与隐藏管理的交互支持：
1. **更新中心卡片交互升级**：
   - 更新卡片右上角新增 Fluent 更多菜单按钮（`...`）；
   - 菜单选项包括：“跳过此版本 (Skip this version)”、“永久锁定当前版本 (Freeze version)”、“隐藏此应用 (Hide)”。
   - 点击“跳过此版本”后，该卡片伴随平滑动效淡出，同时顶部可更新计数徽标实时减 1。
2. **设置中心新增“规则与偏好管理”卡片**：
   - 列表展示当前所有被跳过版本的软件、已锁定的软件与隐藏的软件；
   - 提供“恢复更新”、“解除锁定”与“取消隐藏”的操作按钮。
3. 联动状态实时同步至主界面各个视图。

## Comments

- 严格遵循 Fluent 2.0 动效与上下文菜单规范。

## Answer

已完成前端所有细粒度版本控制与规则管理的交互升级：
1. **类型与 API 封装**：
   - 在 `src/types/index.ts` 中定义了 `UpdateRule` 与 `SignatureInfo`；
   - 在 `src/services/api.ts` 中实现了 `getUpdateRules`、`setAppSkipVersion`、`setAppFrozen`、`setAppHidden`、`removeUpdateRule`、`verifyFileSignature`，并包含纯浏览器 Mock 环境的完整过滤与模拟逻辑。
2. **更新中心交互升级 (`src/views/UpdatesView.tsx`)**：
   - 为每个更新项卡片增加了 Fluent 2.0 风格的更多选项菜单按钮（`···`），点击弹出具有亚克力背景与阴影的上下文菜单；
   - 支持“仅忽略本次提醒”、“跳过此版本（下版再提醒）”、“永久锁定当前版本（忽略所有更新）”与“隐藏此应用”；
   - 触发跳过/锁定/隐藏后，卡片具备 280ms 的缩放与平滑淡出退出动画，并实时更新角标与顶部计数。
3. **设置中心规则管理视图 (`src/views/SettingsView.tsx`)**：
   - 新增独立的分组卡片「🛡️ 版本策略与软件屏蔽规则管理」；
   - 提供四维标签分流切换（全部规则、已跳过版本、已锁定版本、已隐藏应用）；
   - 展示规则状态徽章（跳过版本号、锁定标识、隐藏标识）及设置时间；
   - 提供“恢复此版本”、“解除锁定”、“取消隐藏”、“清空规则”的单键复原能力。
4. **全局状态流转 (`src/App.tsx`)**：
   - 实现了完整的规则变更响应链，更新规则后同步刷新 `updateRules`、`checkForUpdates` 和 `searchApps`，全流程无缝自闭环。
5. **质量验证**：
   - `npm run build` TypeScript 编译与 Vite 打包通过，零错误零警告。
