# ADR-0002: 客户端直连 GitHub API 与加速镜像下载管道

- **状态**: Accepted
- **日期**: 2026-09-03
- **决策者**: 核心工程团队

## 上下文

客户端在不依赖任何自建中心化后端服务器（零服务器开销）的前提下，需要为中国大陆用户提供稳定可靠的发现、检索与大文件二进制下载能力。

## 决策

1. **直连 API + 镜像大文件分流**：
   - GitHub API 元数据查询（JSON）轻量级，优先直接调用官方 REST API，并支持用户配置个人 Personal Access Token（将未登录的 60次/小时上限提升至 5000次/小时）。
   - GitHub Releases 产物（二进制安装包）体积较大，默认通过中国大陆加速镜像节点（如 `gh-proxy.com`、`gitmirror.com`）进行重写代理。
2. **并发测速与自适应故障转移**：
   - 客户端后台定时发起多节点轻量 HEAD 测速，动态选择延迟最低的可用镜像。
   - 当镜像异常或超时时，自动平滑切换至下一可用备用节点，界面右下角通过 Fluent 药丸徽章透明展示当前线路。
