# 数量显示规范

界面里出现的「数量」只有两种合法形态。选哪种只看一个问题：**这个数字是挂在某个标签后面，还是写在一句话里？**

| 形态 | 用在哪 | 写法 |
| --- | --- | --- |
| **A. 数量角标** `<CountBadge>` | 数字跟在一个标签后面：导航项、tab / 分段、筛选 tab、页面 / 区块标题、次级按钮 | `标签` + `<CountBadge value={n} />`；tab 选项用 `<CountLabel>` |
| **B. 叙述计数** | 数字是句子的一部分：副标题、Toast、列表到底提示、卡片元信息、`<option>` 等无法放元素的位置 | i18n 文案直接写，带量词：`{{count}} 款有可用更新` |

## A. 数量角标

实现：[src/components/CountBadge.tsx](../src/components/CountBadge.tsx)，样式 [components-count-badge.css](../src/styles/components-count-badge.css)。

外观（唯一一套，不分尺寸）：

- 18px 高、最小 18px 宽、左右 5px 内边距、4px 圆角（`--radius-xs`）
- 底色 `--bg-acrylic-hover`，1px `--border-subtle` 描边，文字 `--text-tertiary`
- `--font-xs`、字重 510、`tabular-nums`（正文字体，不用等宽字体）
- 选中态 `active`：所属导航项 / tab 被选中时，文字换为 `--color-nav-active`，底色换为 `--brand-subtle`，描边换为 `--border-nav-active`

位置：

- 紧跟标签文本，间距 6px（管理页大标题沿用标题行的 8px），垂直居中；侧边栏导航中右对齐（`margin-left: auto`）
- 标题的角标放在标题元素（`h3` 等）内部
- 一个标签最多挂一个角标
- 父级必须是 flex / inline-flex 容器：角标前带一个空格文本节点，flex 容器里它不占版面，读屏与 `textContent` 则读作「标签 N」

tab / 分段选项用 `<CountLabel icon label count active />`，它负责图标、文本、角标三者的排列，不要手写 inline-flex 包裹层。

零值：

- **容器型位置显示 0**：标题、tab、筛选 tab。0 本身是信息（「已隐藏 0」），也让 tab 宽度保持稳定
- **入口型位置隐藏 0**（`hideZero`）：侧边栏导航、按钮。没有内容时入口上不出现噪点
- **数据未就绪时不渲染**：加载中或加载失败时不显示角标，避免先闪 0 再跳到实际值

上限：超过 999 显示 `999+`。

## B. 叙述计数

- 数字写进 i18n 文案，必须带量词或名词（`{{count}} 款可用`、`共 {{count}} 个`），不要裸数字
- 视觉上就是普通文本：不套底色、不加描边、不用等宽字体

## 一个视图里每个数字只出现一次

同一个数量在一个视图里只在一个位置出现。多个位置都能放时，按优先级取第一个：

1. 筛选 tab / 分段（可交互，且本来就要逐项显示）
2. 标题角标
3. 副标题等叙述文本
4. 按钮

侧边栏是全局导航，不计入视图，可与视图内数量并存。

由此得出：

- 已安装页：数量全在筛选 tab 上，标题不挂角标；副标题只写 tab 上没有的信息（「N 款有可用更新」）
- 更新页：有筛选 tab 时标题不挂角标；副标题不复述升级数与规则数；「全部更新」按钮不带数字
- 规则管理弹窗：数量在「全部」tab 上，标题不挂角标
- 导入弹窗：摘要已写「已选 N 款」，「添加」按钮不带数字

## 禁止

- **括号计数**：`草稿 (2)`、`Favorites ({{count}})`、`（3）`。i18n 标签文案只放标签本身，数字交给 `CountBadge`
- **彩色 / 实心计数**：品牌色实心胶囊、蓝底白字等。数量是中性信息，不承担提醒职责
- **悬空数字**：没有标签可挂、又不是句子的孤立数字（工具栏角落的「共 13 个项目」、图表旁的裸总数）。挂到对应标题的角标上
- **静态结构数量**：表单分组的字段数等固定不变的数字。数量只用来描述数据
- **各视图自造计数样式**：新增数量显示一律复用 `CountBadge` / `CountLabel`，不新增 `*-count` / `*-pill` 类

## 不属于数量的标记

- **状态标签**（已归档、本地收录、已锁定）：文字型标记，用 `.status-tag`（[components-status-tag.css](../src/styles/components-status-tag.css)），外观与数量角标同族但不承载数字
- **平台筛选芯片内计数**（侧边栏平台栅格中图标下方的小号数字）：芯片本身就是标签，数字作为芯片的第二行注脚，不另加角标
- **版本号、进度（`3 / 12`）、星数增量（`+120`）**：属于数据值，按各自组件展示
